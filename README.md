# lilufo

lilufo is a proposed open font source format for variable, procedural,
and AI-assisted typography. It is inspired by UFO.

This repository holds the specification, planning documents, and
documentation for the format. Nothing here is final. The format may
still turn out to be a set of contributions to UFO and Designspace
rather than a new format.

## Layout

- `proposals/` — design sketches and proposals, dated
- `research/` — prior-art notes and comparisons
- `spec/` — the specification, once a draft exists
- `DECISIONS.md` — the decision log

## Status

Exploratory. See `proposals/2026-10-18-design-proposal.md` for the
first sketch.
